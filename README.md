## 🛠️ Project Overview
Built an interactive dashboard to analyze global Netflix content trends, focusing on genre distribution and production growth.

### Key Technical Achievements:
* **Data Transformation:** Performed ETL in **Power Query (M)** to clean 8k+ records and handle multi-genre string manipulation.
* **DAX Modeling:** Developed custom measures for **Total Titles**, **Movies vs TV Shows**, and **Content Growth** trends.
* **Visual Identity:** Integrated **UI/UX principles** into data visualizations, using Line, Bar, and Donut charts within a custom Netflix-themed layout to emphasize visual hierarchy.
* **Interactivity:** Implemented **Synchronized Slicers** (Year, Type, Country) for dynamic, user-driven data exploration.
